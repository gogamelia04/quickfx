# Quick FX

ეფექტებისა და პრესეტების სწრაფი ძებნა Adobe Premiere Pro-სთვის (Mac).
მონიშნე კლიპი → **⌥Space** → აკრიფე ეფექტის ან პრესეტის სახელი → **Enter**.

## დაყენება და განახლება

გახსენი Terminal, ჩასვი ეს ხაზი და დააჭირე Enter-ს:

```
curl -fsSL https://raw.githubusercontent.com/gogamelia04/quickfx/main/install.sh | bash
```

მერე:

1. გახსნილ ფანჯარაში (Privacy & Security → Accessibility) ჩართე **Hammerspoon**.
2. Premiere სრულად დახურე (⌘Q) და თავიდან გახსენი.

ახალი ვერსიის მისაღებად იგივე ხაზი თავიდან გაუშვი.

## წაშლა

```
curl -fsSL https://raw.githubusercontent.com/gogamelia04/quickfx/main/install.sh | bash -s -- uninstall
```
