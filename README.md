### შეჯიბრი (გრაფიკაში)

- 2-დან 6 მონაწილემდე: სახელები, ქულები, თითოს თავისი ფერი და ფოტო.
- ქულის დამატება ერთს, რამდენიმეს ან ყველას ერთად, სხვადასხვა რაოდენობით (ჯარიმაც: `-1`) — 24 სტილში.
- ქულების ცხრილი, პოდიუმი, გამარჯვებული, VS, „ვისი ჯერია“, „გამოეთიშა“; რბოლის და დრიფტის გაფორმებაც.

## დაყენება და განახლება

გახსენი Terminal, ჩასვი ეს ხაზი და დააჭირე Enter-ს:

```
curl -fsSL https://raw.githubusercontent.com/gogamelia04/quickfx/main/install.sh | bash
```

მერე:

1. გახსნილ ფანჯარაში (Privacy & Security → Accessibility) ჩართე **Hammerspoon**.
2. Premiere სრულად დახურე (⌘Q) და თავიდან გახსენი.

ახალი ვერსიის მისაღებად იგივე ხაზი თავიდან გაუშვი და Premiere თავიდან გახსენი.

„ხმები“ კითხულობს საქაღალდეს `Documents/Quick FX Sounds` (ქვესაქაღალდე = კატეგორია). ხმების პაკეტი ამ რეპოზიტორიაში არ დევს.

„ჩაწერა“ და „გრაფიკა“ პირველ გამოყენებაზე ერთხელ ჩამოტვირთავს ძრავას (120–160 MB) — ღილაკი „დაყენება“.

## ბოლო ცვლილებები

- **1.30** — „ქონექთი“ 140 დიზაინამდე გაიზარდა. ავტო შოუ სამ მანქანაზეა აწყობილი: მანქანების სია ერთხელ იწერება; VS სამი მანქანა, ტესტების შედეგები (დრაგი, 0–100, მუხრუჭები, ხარჯი, მუს-ტესტი…), ვიზუალის შეფასება (წამყვანების ქულები, სრული ცხრილი, კრიტერიუმები), ქულები, კვარცხლბეკი. პოდკასტსა და ნიუსებსაც დაემატა დიზაინები; სლოგანი და გათამაშება.
- **1.29** — „გრაფიკა“-ში ახალი კატეგორია „ქონექთი“: 64 დიზაინი არხის ლოგოთი, ფერებით და ფონტით — პოდკასტი, ნიუსები, ავტო შოუ. ფონტი (Loos) ცალკე უნდა იყოს Mac-ზე.
- **1.28** — ახალი ხელსაწყო „ჩასმა“ (⌘9): დაკოპირებული ფოტო ⌘V-ით პირდაპირ პროექტში და timeline-ზე. Escape ერთი დაჭერით მალავს ფანჯარას ნებისმიერი ხელსაწყოდან.
- **1.27** — გრაფიკა ზოგ Mac-ზე შავი ფონით ან შეცვლილი ფერებით ჩანდა: ახლა QuickTime Animation ფორმატით იწერება. ძველი ფაილებისთვის „გრაფიკა“-ში ჩნდება ღილაკი „ძველი გრაფიკის გასწორება“ (მერე Premiere თავიდან გახსენი).
- **1.26** — შეჯიბრი: მონაწილის ფოტო სახელის პირველი ასოს ნაცვლად.
- **1.25** — შეჯიბრი: ქულა რამდენიმე მონაწილეს ერთად, თითოს თავისი ფერი, „ქულა ემატება“ 24 სტილში.
- **1.24** — ახალი კატეგორია „შეჯიბრი“; „ეკრანზე“ — რამდენ ხანს დარჩეს გრაფიკა (10 წუთამდე), შემოსვლის/გასვლის გამორთვა.
- **1.23** — ფერის ამრჩევი; ავტო, დრიფტის და რბოლის დიზაინები ყველა კატეგორიაში.
- **1.21–1.22** — ფონტების სია Premiere-ის მსგავსად, სტილები, ბარათებად დალაგებული სია.
- **1.20** — „გრაფიკა“ (წამზომები, ქვედა ტიტრები, სოც. ქსელები); Cinematic ტექსტის ანიმაციები; „პაუზები“ ამოღებულია.
