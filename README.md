# Quick FX

Adobe Premiere Pro-ს პლაგინი მონტაჟორებისთვის (Mac). იხსნება **⌥Space**-ით.

| | ხელსაწყო | რას აკეთებს |
|---|---|---|
| ⌘1 | **ეფექტები** | ეფექტებისა და პრესეტების სწრაფი ძებნა: მონიშნე კლიპი → აკრიფე → Enter. რჩეულები: ⌘D |
| ⌘2 | **ფაილები** | პროექტის საქაღალდის გარეთ დარჩენილი მედია თავისით კოპირდება `Imported`-ში |
| ⌘3 | **ზონები** | Safe Zones: TikTok, Reels, Shorts, Stories, YouTube 16:9 |
| ⌘4 | **მრუდი** | keyframe-ების სიჩქარე After Effects-ის speed graph-ის მსგავსად (Easy Ease: F9) |
| ⌘5 | **ჩაწერა** | YouTube-იდან და TikTok-იდან ვიდეო, მხოლოდ ვიდეო ან მხოლოდ ხმა პირდაპირ Project პანელში; მონაკვეთი და რიგი |

დაწვრილებით: დაყენების შემდეგ `README.txt` (არქივშია).

## დაყენება და განახლება

გახსენი Terminal, ჩასვი ეს ხაზი და დააჭირე Enter-ს:

```
curl -fsSL https://raw.githubusercontent.com/gogamelia04/quickfx/main/install.sh | bash
```

მერე:

1. გახსნილ ფანჯარაში (Privacy & Security → Accessibility) ჩართე **Hammerspoon**.
2. Premiere სრულად დახურე (⌘Q) და თავიდან გახსენი.

ახალი ვერსიის მისაღებად იგივე ხაზი თავიდან გაუშვი და Premiere თავიდან გახსენი.

„ჩაწერა“ პირველ გამოყენებაზე ერთხელ ჩამოტვირთავს თავის ძრავას (120–160 MB) — ღილაკი „დაყენება“.
